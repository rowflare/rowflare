# Views Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add calendar, timeline and gallery views and multi-level grid grouping with summaries, backed by date-window and grouped queries in the Durable Object.

**Architecture:** The engine gains a `range` filter (span overlap computed in SQL, including start plus duration), multi-level group ordering with per-row group keys, and an aggregate mode without fan-out whose keys match those group keys. The browser gets two pure modules (`dates.ts`, `gridGroups.ts`) that hold all date and grouping logic, a few data-layer additions in `BaseClient`, a shared card component, and four view components built with React and CSS (no calendar or Gantt library).

**Tech Stack:** Cloudflare Workers + SQLite Durable Object, Hono, React 18, Glide Data Grid 6, Vitest (node project for pure modules, workerd project for engine and API), Playwright MCP for manual UI verification.

**Spec:** `docs/superpowers/specs/2026-10-13-views-design.md`

## Global Constraints

- No git operations of any kind (user rule). Replace commit steps with the checkpoint commands given.
- No Chinese in code or comments. No em dash characters anywhere.
- Match surrounding code style: 2-space indent, double quotes, semicolons, long lines allowed, comments only where the code is not obvious.
- No new npm dependencies.
- At most 3 grid group levels; range windows at most 3 years (1,100 days); range dates are `YYYY-MM-DD`.
- Timeline windows: 90 days (day scale), 364 days (week scale), 1,095 days (month scale); edge threshold 15%, shift one third of the window.
- Calendar and timeline queries ask for up to 2,000 rows inline; remaining rows load through `ensureRows`.
- Collapsed grid groups are stored per viewer in `localStorage` under `rf-collapsed:<viewId>`, every access wrapped in try/catch.
- REST API behavior must not change; existing tests must keep passing.
- Performance targets from the spec: calendar month window query under 300 ms on the 50,000-row bench; grouped query plus summaries for 2 levels under 1 s locally.

## Review Focus

1. A record whose end date is earlier than its start date must still appear (as one day) in calendar, timeline and range queries, and dragging must not produce end before start. Pinned in Task 1 (`range treats an end before start as a single day`) and Task 3 (`spanOf collapses a backwards span`).
2. Deleting a field that a calendar, timeline, gallery or grouped grid depends on must leave the view usable (setup screen), not crash. Pinned in Task 1 (`deleteField clears every view reference`).
3. Multi-select and link group keys from the grouped query must equal the summary keys from aggregate, otherwise headers show no summaries. Pinned in Task 2 (`aggregate without fan-out uses the same keys as grouped queries`).
4. Collapsing a parent group must hide all nested headers and records under it, but not its siblings. Pinned in Task 4 (`collapsing a parent hides nested headers and records`).
5. Datetime values must keep their time of day when moved to another day, in any browser time zone. Pinned in Task 3 (`withDay keeps the time of day`).

```ts
/** The date part (YYYY-MM-DD, UTC) of a date-like field as SQL text. */
export function dayExpr(f: Field): string {
  if (f.type === "createdTime" || f.type === "modifiedTime") return `strftime('%Y-%m-%d', ${valueExpr(f)} / 1000, 'unixepoch')`;
  return `substr(${valueExpr(f)}, 1, 10)`;
}

export interface DateRange {
  startFieldId: string;
  endFieldId?: string;
  durationFieldId?: string;
  from: string;
  to: string;
}

/**
 * Records whose [start, end] span overlaps [from, to]. The end is the end field, or start plus
 * (duration - 1) days, or the start; an end before the start counts as the start. Fields are validated by the caller.
 */
export function rangeSql(r: DateRange, fields: Map<string, Field>): SqlPart {
  const s = dayExpr(fields.get(r.startFieldId)!);
  const endField = r.endFieldId ? fields.get(r.endFieldId) : undefined;
  const durField = !endField && r.durationFieldId ? fields.get(r.durationFieldId) : undefined;
  const e = endField
    ? `coalesce(${dayExpr(endField)}, ${s})`
    : durField
      ? `date(${s}, '+' || (max(coalesce(cast(${valueExpr(durField)} AS INTEGER), 1), 1) - 1) || ' days')`
      : s;
  return { sql: `(${s} IS NOT NULL AND ${s} <= ? AND max(${s}, coalesce(${e}, ${s})) >= ?)`, params: [r.to, r.from] };
}
```

```ts
  private checkRange(r: DateRange, fields: Map<string, Field>) {
    const day = /^\d{4}-\d{2}-\d{2}$/;
    if (!day.test(r.from) || !day.test(r.to)) throw new UserError("Range dates must look like 2026-01-31");
    if (r.from > r.to) throw new UserError("Range start must not be after its end");
    if ((Date.parse(r.to) - Date.parse(r.from)) / 86400000 > 1100) throw new UserError("A range can span at most 3 years");
    const start = fields.get(r.startFieldId);
    if (!start || !isDateField(start)) throw new UserError("The start field must be a date field");
    if (r.endFieldId) {
      const end = fields.get(r.endFieldId);
      if (!end || !isDateField(end)) throw new UserError("The end field must be a date field");
    }
    if (r.durationFieldId) {
```

```ts
// Date math for calendar and timeline views. Days are YYYY-MM-DD strings computed in UTC, so no DST drift;
// only reading datetime values and building new ones uses the browser's time zone.
export type Day = string;

const MS = 86400000;
const pad = (n: number) => String(n).padStart(2, "0");
const MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];
const FULL_MONTHS = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];
const WEEKDAYS = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"];

export const parseDay = (d: Day): number => Date.UTC(+d.slice(0, 4), +d.slice(5, 7) - 1, +d.slice(8, 10));

export function toDay(ms: number): Day {
  const x = new Date(ms);
  return `${x.getUTCFullYear()}-${pad(x.getUTCMonth() + 1)}-${pad(x.getUTCDate())}`;
}

export const addDays = (d: Day, n: number): Day => toDay(parseDay(d) + n * MS);
export const diffDays = (a: Day, b: Day): number => Math.round((parseDay(b) - parseDay(a)) / MS);
export const minDay = (a: Day, b: Day): Day => (a < b ? a : b);
export const maxDay = (a: Day, b: Day): Day => (a > b ? a : b);

/** Weeks start on Monday. */
export function startOfWeek(d: Day): Day {
  return addDays(d, -((new Date(parseDay(d)).getUTCDay() + 6) % 7));
}

export const startOfMonth = (d: Day): Day => d.slice(0, 8) + "01";

export function addMonths(d: Day, n: number): Day {
  const y = +d.slice(0, 4), m = +d.slice(5, 7) - 1 + n, day = +d.slice(8, 10);
  const last = new Date(Date.UTC(y, m + 1, 0)).getUTCDate();
  return toDay(Date.UTC(y, m, Math.min(day, last)));
}

export function monthGrid(d: Day): Day[][] {
  const start = startOfWeek(startOfMonth(d));
  return Array.from({ length: 6 }, (_, w) => Array.from({ length: 7 }, (_, i) => addDays(start, w * 7 + i)));
}

export const weekDays = (d: Day): Day[] => Array.from({ length: 7 }, (_, i) => addDays(startOfWeek(d), i));

export const localDay = (date: Date = new Date()): Day => `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}`;

/** The calendar day of a stored value: date-only strings as-is, datetimes and timestamps in the browser's time zone. */
export function dayOf(v: unknown): Day | null {
  if (typeof v === "number") return Number.isFinite(v) ? localDay(new Date(v)) : null;
  if (typeof v !== "string" || !v) return null;
  if (/^\d{4}-\d{2}-\d{2}$/.test(v)) return v;
  const t = Date.parse(v);
  return Number.isNaN(t) ? null : localDay(new Date(t));
}

/** Minutes after local midnight for datetime values; null for date-only values. */
export function minutesOf(v: unknown): number | null {
  if (typeof v === "string" && /^\d{4}-\d{2}-\d{2}$/.test(v)) return null;
  const t = typeof v === "number" ? v : typeof v === "string" ? Date.parse(v) : NaN;
  if (!Number.isFinite(t)) return null;
  const d = new Date(t);
  return d.getHours() * 60 + d.getMinutes();
}

/** An ISO datetime for a local day and time. */
export function atMinutes(day: Day, minutes: number): string {
  return new Date(+day.slice(0, 4), +day.slice(5, 7) - 1, +day.slice(8, 10), Math.floor(minutes / 60), minutes % 60).toISOString();
}

/** A new stored value on `day`, keeping the time of day of a datetime value (9:00 when there was none). */
export function withDay(old: unknown, day: Day, includeTime: boolean): string {
  if (!includeTime) return day;
  return atMinutes(day, minutesOf(old) ?? 9 * 60);
}

export interface Span {
  start: Day;
  end: Day;
}

/** A record's span; a missing or earlier end means a single day. Duration counts days including the start. */
export function spanOf(start: unknown, end: unknown, durationDays?: unknown): Span | null {
  const s = dayOf(start);
  if (!s) return null;
  let e = dayOf(end);
  if (!e && typeof durationDays === "number" && durationDays >= 1) e = addDays(s, Math.floor(durationDays) - 1);
  return { start: s, end: e && e > s ? e : s };
}

export const overlaps = (s: Span, from: Day, to: Day): boolean => s.start <= to && s.end >= from;

export function clip(s: Span, from: Day, to: Day): (Span & { cutStart: boolean; cutEnd: boolean }) | null {
  if (!overlaps(s, from, to)) return null;
  return { start: maxDay(s.start, from), end: minDay(s.end, to), cutStart: s.start < from, cutEnd: s.end > to };
}

/** Greedy packing: by start (longer first on ties), each span takes the first row whose last span ended before it. */
export function packRows<T extends Span>(items: T[]): (T & { row: number })[] {
  const sorted = [...items].sort((a, b) => (a.start < b.start ? -1 : a.start > b.start ? 1 : diffDays(b.start, b.end) - diffDays(a.start, a.end)));
  const ends: Day[] = [];
  return sorted.map(it => {
    let row = ends.findIndex(e => e < it.start);
    if (row < 0) {
      row = ends.length;
      ends.push(it.end);
    } else ends[row] = it.end;
    return { ...it, row };
  });
}

export type Scale = "day" | "week" | "month";
export const PX_PER_DAY: Record<Scale, number> = { day: 40, week: 16, month: 4 };
export const WINDOW_DAYS: Record<Scale, number> = { day: 90, week: 364, month: 1095 };

export const dayToX = (d: Day, origin: Day, px: number): number => diffDays(origin, d) * px;
export const xToDay = (x: number, origin: Day, px: number): Day => addDays(origin, Math.floor(x / px));

export interface Tick {
  day: Day;
  label: string;
  major: boolean;
}

/** Day scale: every day, major on Mondays. Week scale: Mondays, major at a new month. Month scale: first days, major in January. */
export function axisTicks(from: Day, to: Day, scale: Scale): Tick[] {
  const out: Tick[] = [];
  const mon = (d: Day) => MONTHS[+d.slice(5, 7) - 1];
  if (scale === "month") {
    for (let d = startOfMonth(from); d <= to; d = addMonths(d, 1)) {
      if (d < from) continue;
      const jan = d.slice(5, 7) === "01";
      out.push({ day: d, label: jan ? `${mon(d)} ${d.slice(0, 4)}` : mon(d), major: jan });
    }
    return out;
  }
  if (scale === "week") {
    let d = startOfWeek(from);
    if (d < from) d = addDays(d, 7);
    let prev = "";
    for (; d <= to; d = addDays(d, 7)) {
      const m = d.slice(0, 7);
      out.push({ day: d, label: m !== prev ? `${mon(d)} ${+d.slice(8)}` : String(+d.slice(8)), major: m !== prev });
      prev = m;
    }
    return out;
  }
  for (let d = from; d <= to; d = addDays(d, 1)) out.push({ day: d, label: String(+d.slice(8)), major: new Date(parseDay(d)).getUTCDay() === 1 });
  return out;
}

export const monthLabel = (d: Day): string => `${FULL_MONTHS[+d.slice(5, 7) - 1]} ${d.slice(0, 4)}`;
export const dayLabel = (d: Day): string => `${WEEKDAYS[(new Date(parseDay(d)).getUTCDay() + 6) % 7]} ${+d.slice(8)}`;
export const WEEKDAY_NAMES = WEEKDAYS;
export const fmtMinutes = (m: number): string => `${Math.floor(m / 60)}:${pad(m % 60)}`;
```

```ts
// Display rows for a grouped grid: group header rows interleaved with record rows, with collapsing.
// The server orders ids by the group fields, so every group is one consecutive run.
import type { Field, SummaryFn } from "../../shared/types";
import { COMPUTED_TYPES } from "../../shared/types";
import { displayCell } from "../../shared/cells";

export type GroupKey = string | null;

export interface HeaderRow {
  kind: "header";
  level: number;
  keys: GroupKey[];
  path: string;
  count: number;
}

export interface RecordRow {
  kind: "record";
  id: number;
}

export type DisplayRow = HeaderRow | RecordRow;

export const pathOf = (keys: GroupKey[]): string => JSON.stringify(keys);

function norm(keys: GroupKey[] | undefined, levels: number): GroupKey[] {
  const out = (keys ?? []).slice(0, levels);
  while (out.length < levels) out.push(null);
  return out;
}

/** True when a group above `depth` levels (paths of length 1..depth) is collapsed. */
function hidden(keys: GroupKey[], depth: number, collapsed: ReadonlySet<string>): boolean {
  for (let l = 1; l <= depth; l++) if (collapsed.has(pathOf(keys.slice(0, l)))) return true;
  return false;
}

export function buildRows(ids: number[], groupKeys: GroupKey[][], levels: number, collapsed: ReadonlySet<string>): DisplayRow[] {
  const counts = new Map<string, number>();
  for (let i = 0; i < ids.length; i++) {
    const keys = norm(groupKeys[i], levels);
    for (let l = 1; l <= levels; l++) {
      const p = pathOf(keys.slice(0, l));
      counts.set(p, (counts.get(p) ?? 0) + 1);
    }
  }
  const out: DisplayRow[] = [];
  let prev: GroupKey[] | null = null;
  for (let i = 0; i < ids.length; i++) {
    const keys = norm(groupKeys[i], levels);
    let from = 0;
    if (prev) while (from < levels && prev[from] === keys[from]) from++;
    for (let l = from; l < levels; l++) {
      if (hidden(keys, l, collapsed)) break;
      const p = pathOf(keys.slice(0, l + 1));
      out.push({ kind: "header", level: l, keys: keys.slice(0, l + 1), path: p, count: counts.get(p) ?? 0 });
    }
    prev = keys;
    if (!hidden(keys, levels, collapsed)) out.push({ kind: "record", id: ids[i]! });
  }
  return out;
}

const NUMERIC_TYPES = new Set(["number", "autonumber", "createdTime", "modifiedTime"]);

function parseKey(f: Field, key: string): unknown {
  if (key.startsWith("[") || key.startsWith("{")) {
    try {
      return JSON.parse(key);
    } catch {
      return key;
    }
  }
  if (NUMERIC_TYPES.has(f.type) || ((f.type === "formula" || f.type === "rollup") && f.options.resultType === "number")) return Number(key);
  return key;
}

export function headerLabel(f: Field | undefined, key: GroupKey, userName: (id: string) => string): string {
  if (key === null) return "(Empty)";
  if (!f) return key;
  if (f.type === "checkbox") return key === "1" || key === "true" ? "Checked" : "Unchecked";
  return displayCell(f, parseKey(f, key), { userName }) || "(Empty)";
}

/** Cells a new record needs so it lands in the group with these keys; computed fields are skipped. */
export function groupCells(fields: (Field | undefined)[], keys: GroupKey[]): Record<string, unknown> {
  const out: Record<string, unknown> = {};
  keys.forEach((k, i) => {
    const f = fields[i];
    if (!f || k === null || COMPUTED_TYPES.has(f.type)) return;
    out[f.id] = f.type === "checkbox" ? k === "1" || k === "true" : parseKey(f, k);
  });
  return out;
}

export const SUMMARY_LABELS: Record<SummaryFn, string> = { sum: "Sum", avg: "Average", min: "Min", max: "Max", countFilled: "Filled", countUnique: "Unique" };

export function summaryText(f: Field, fn: SummaryFn, value: number | string | null | undefined): string {
  if (value === null || value === undefined) return "";
  const shown = fn === "countFilled" || fn === "countUnique" ? String(value) : displayCell(f, value, {});
  return `${SUMMARY_LABELS[fn]} ${shown}`;
}
```

```tsx
import { useEffect, useRef, useState } from "react";
import type { Cells, Field, View } from "../../shared/types";
import { COMPUTED_TYPES } from "../../shared/types";
import { Button, Empty, Icon, Popover, Spinner } from "../ui";
import { type BaseClient, primaryText, useBase } from "./client";
import { isEmpty, valueOf } from "./cards";
import { DateSetup, dateFields } from "./DateSetup";
import { WEEKDAY_NAMES, addDays, addMonths, atMinutes, clip, dayLabel, diffDays, fmtMinutes, localDay, minutesOf, monthGrid, monthLabel, packRows, spanOf, weekDays, withDay, type Day, type Span } from "./dates";
import "./views.css";

const LANES = 3; // bars per week row in month mode before "+N more"
const BAR_H = 22;
const DAY_HEAD = 26;
const HOUR_H = 40;

interface Item extends Span {
  id: number;
  title: string;
  /** Start minutes of single-day records whose start has a time of day; null for all-day records. */
  minutes: number | null;
  endMinutes: number | null;
}

interface Drag {
  id: number;
  mode: "move" | "start" | "end";
  /** Days between the item's start and the day the pointer grabbed. */
  grab: number;
}

type Seg = Span & { cutStart: boolean; cutEnd: boolean };

interface Props {
  client: BaseClient;
  view: View;
  search: string;
  onExpand: (rowId: number) => void;
}

export default function CalendarView(props: Props) {
  useBase(props.client);
  const view = props.client.view(props.view.id) ?? props.view;
  const options = dateFields(props.client, view.tableId);
  const start = options.find(f => f.id === view.config.dateFieldId);
  if (!start) return <DateSetup client={props.client} view={view} icon="calendar" title="Show records on a calendar" text="Choose the date field that places each record on the calendar." />;
  return <CalendarBody {...props} view={view} start={start} end={options.find(f => f.id === view.config.endDateFieldId && f.id !== start.id)} options={options} />;
}

function CalendarBody({ client, view, search, onExpand, start, end, options }: Props & { start: Field; end?: Field; options: Field[] }) {
  const tableId = view.tableId;
  const mode = view.config.calendarMode ?? "month";
  const [anchor, setAnchor] = useState<Day>(() => localDay());
  const [side, setSide] = useState(false);
  const [settings, setSettings] = useState<HTMLElement | null>(null);
  const [more, setMore] = useState<{ day: Day; anchor: HTMLElement } | null>(null);
  const [over, setOver] = useState<string | null>(null);
  const drag = useRef<Drag | null>(null);
  const body = useRef<HTMLDivElement>(null);
  const weeks = mode === "month" ? monthGrid(anchor) : [weekDays(anchor)];
  const from = weeks[0]![0]!;
  const to = weeks[weeks.length - 1]![6]!;

  useEffect(() => {
    client.setViewRange(view.id, from, to, search);
  }, [client, view.id, from, to, search]);

  useEffect(() => {
    if (body.current) body.current.scrollTop = 8 * HOUR_H;
  }, [mode]);

  const st = client.viewState(view.id);
  const ids = st?.ids ?? [];
  useEffect(() => {
    client.ensureRows(tableId, ids);
  });

  const editable = client.writable && !COMPUTED_TYPES.has(start.type) && (!end || !COMPUTED_TYPES.has(end.type));
  const timedStart = start.type !== "date" || !!start.options.includeTime;
  const items: Item[] = [];
  for (const id of ids) {
    const row = client.row(tableId, id);
    if (!row) continue;
    const sv = valueOf(start, row);
    const ev = end ? valueOf(end, row) : undefined;
    const span = spanOf(sv, ev);
    if (!span) continue;
    const single = span.start === span.end;
    items.push({ id, ...span, title: primaryText(client, tableId, row) || "Unnamed record", minutes: single && timedStart ? minutesOf(sv) : null, endMinutes: single && end ? minutesOf(ev) : null });
  }

  const write = (id: number, next: Span, time?: { start: number; end: number | null }) => {
    const row = client.row(tableId, id);
    if (!row || !editable) return;
    const cells: Cells = {};
    cells[start.id] = time && start.options.includeTime ? atMinutes(next.start, time.start) : withDay(valueOf(start, row), next.start, !!start.options.includeTime);
    if (end && (!isEmpty(valueOf(end, row)) || next.end !== next.start)) {
      cells[end.id] = time && time.end !== null && end.options.includeTime ? atMinutes(next.end, time.end) : withDay(valueOf(end, row), next.end, !!end.options.includeTime);
    }
    client.updateCells(tableId, [{ id, cells }], { label: "Reschedule" });
  };

  const dropOn = (day: Day, minutes?: number) => {
    const d = drag.current;
    drag.current = null;
    setOver(null);
    if (!d) return;
    const it = items.find(x => x.id === d.id);
    if (!it) return write(d.id, { start: day, end: day }, minutes === undefined ? undefined : { start: minutes, end: end ? minutes + 60 : null });
    if (d.mode === "start") return write(it.id, { start: day <= it.end ? day : it.end, end: it.end });
    if (d.mode === "end") return write(it.id, { start: it.start, end: day >= it.start ? day : it.start });
    const s = addDays(day, -d.grab);
    const time = minutes === undefined ? undefined : { start: minutes, end: it.minutes !== null && it.endMinutes !== null ? minutes + (it.endMinutes - it.minutes) : null };
    write(it.id, { start: s, end: addDays(s, diffDays(it.start, it.end)) }, time);
  };

  const create = async (day: Day, minutes?: number) => {
    if (!editable) return;
    const m = minutes ?? 9 * 60;
    const cells: Cells = { [start.id]: start.options.includeTime ? atMinutes(day, m) : day };
    if (end && minutes !== undefined && end.options.includeTime) cells[end.id] = atMinutes(day, m + 60);
    const rows = await client.createRows(tableId, [{ cells }]);
    if (rows[0]) onExpand(rows[0].id);
  };

  const startDrag = (e: React.DragEvent, d: Drag) => {
    e.stopPropagation();
    drag.current = d;
    e.dataTransfer.effectAllowed = "move";
    e.dataTransfer.setData("text/plain", String(d.id));
  };
  const endDrag = () => {
    drag.current = null;
    setOver(null);
  };
  const dropTarget = (key: string, onDrop: (e: React.DragEvent<HTMLElement>) => void) => ({
    onDragOver: (e: React.DragEvent<HTMLElement>) => {
      if (!drag.current) return;
      e.preventDefault();
      e.dataTransfer.dropEffect = "move";
      if (over !== key) setOver(key);
    },
    onDragLeave: (e: React.DragEvent<HTMLElement>) => {
      if (!e.currentTarget.contains(e.relatedTarget as Node)) setOver(o => (o === key ? null : o));
    },
    onDrop: (e: React.DragEvent<HTMLElement>) => {
      e.preventDefault();
      onDrop(e);
    },
  });
  const slotMinutes = (e: React.MouseEvent<HTMLElement>) => {
    const r = e.currentTarget.getBoundingClientRect();
    return Math.min(23 * 60 + 30, Math.max(0, Math.round((((e.clientY - r.top) / HOUR_H) * 60) / 30) * 30));
  };

  const bar = (it: Item, seg: Seg, style: React.CSSProperties) => (
    <div
      key={`${it.id}:${seg.start}`}
      className={"cal-bar" + (seg.cutStart ? " cut-start" : "") + (seg.cutEnd ? " cut-end" : "")}
      style={style}
      title={it.title}
      draggable={editable}

        const r = e.currentTarget.getBoundingClientRect();
        const days = diffDays(seg.start, seg.end) + 1;
        const at = Math.min(days - 1, Math.max(0, Math.floor(((e.clientX - r.left) / r.width) * days)));

      }}
      onDragEnd={endDrag}

      <div className="kb-toolbar cal-toolbar">
        <div className="cal-nav">

          <button className="icon-btn" aria-label="Previous" onClick={() => step(-1)}><Icon name="back" size={16} /></button>

        </div>

            ))}
          </div>
          <button className={"btn btn-sm btn-ghost" + (side ? " active" : "")} onClick={() => setSide(s => !s)}>Unscheduled {unscheduled.length >= 200 ? "200+" : unscheduled.length}</button>
          <button className={"btn btn-sm btn-ghost" + (settings ? " active" : "")} onClick={e => setSettings(settings ? null : e.currentTarget)}><Icon name="settings" size={14} /> Settings</button>
        </div>
        {settings && (
          <Popover anchor={settings} onClose={() => setSettings(null)} width={280} align="end" className="kb-settings">
            <label className="field-label">Date field</label>
            <select className="input" disabled={!client.writable} value={start.id} onChange={e => client.updateViewConfig(view.id, { dateFieldId: e.target.value })}>
              {options.map(f => <option key={f.id} value={f.id}>{f.name}</option>)}
            </select>
            <label className="field-label">End date (optional)</label>
            <select className="input" disabled={!client.writable} value={end?.id ?? ""} onChange={e => client.updateViewConfig(view.id, { endDateFieldId: e.target.value || undefined })}>

            </select>
          </Popover>
        )}
      </div>
      {st?.error ? (
        <Empty title="Could not load records">
          <div className="muted">{st.error}</div>
          <Button small onClick={() => client.queryView(view.id, search)}>Retry</Button>
        </Empty>

          {mode === "month" ? monthBody : weekBody}
          {side && (
            <aside className="cal-side">
              <div className="cal-side-head">Unscheduled</div>
              {unscheduled.length === 0 && <div className="muted small">Every record has a date.</div>}
              {unscheduled.map(id => {
                const row = client.row(tableId, id);
                return (
                  <div key={id} className="cal-side-item" draggable={editable} onDragStart={e => startDrag(e, { id, mode: "move", grab: 0 })} onDragEnd={endDrag} onClick={() => onExpand(id)}>
                    {row ? primaryText(client, tableId, row) || "Unnamed record" : "Loading..."}
                  </div>
                );
              })}
            </aside>
          )}
        </div>
      )}
      {more && (
        <Popover anchor={more.anchor} onClose={() => setMore(null)} width={260} className="menu">
          <div className="cal-more-title">{dayLabel(more.day)}</div>
          {items.filter(it => it.start <= more.day && it.end >= more.day).map(it => (
            <button key={it.id} className="menu-item" onClick={() => { setMore(null); onExpand(it.id); }}>
              {it.minutes !== null && <span className="cal-time">{fmtMinutes(it.minutes)}</span>} {it.title}
            </button>
          ))}
        </Popover>
      )}
    </div>
  );
}
```

```tsx
// Timeline view: bars from a start date and an end date (or a duration) on a scrollable time axis, in lanes.
import { useEffect, useLayoutEffect, useRef, useState } from "react";
import type { Cells, Field, Row, View } from "../../shared/types";
import { COMPUTED_TYPES, isNumberField } from "../../shared/types";
import { Button, Empty, Icon, Popover, Spinner } from "../ui";
import { type BaseClient, primaryText, useBase } from "./client";
import { isEmpty, valueOf } from "./cards";
import { DateSetup, dateFields } from "./DateSetup";
import { PX_PER_DAY, WINDOW_DAYS, addDays, axisTicks, clip, dayToX, diffDays, localDay, monthLabel, packRows, spanOf, withDay, xToDay, type Day, type Scale, type Span } from "./dates";
import "./views.css";

const NONE = "__none";
const ROW_H = 30;
const LEFT_W = 200;

interface Lane {
  key: string;
  name: string;
  color?: string;
}

interface Bar extends Span {
  id: number;
  title: string;
  lane: string;
}

interface Drag {
  id: number;
  lane: string;
  mode: "move" | "start" | "end" | "place";
  x0: number;
  dx: number;
  overLane: string;
}

interface Props {
  client: BaseClient;
  view: View;
  search: string;
  onExpand: (rowId: number) => void;
}

const LANE_TYPES = new Set(["singleSelect", "user", "link"]);

/** Lane keys of a record: option id, user id or linked record id; NONE when empty; "" when there are no lanes. */
function laneKeys(f: Field | undefined, row: Row): string[] {
  if (!f) return [""];
  const v = valueOf(f, row);
  if (isEmpty(v)) return [NONE];
  if (f.type === "link") return (v as { id: number }[]).map(x => String(x.id));
  return (Array.isArray(v) ? v : [v]).map(String);
}

function lanesFor(client: BaseClient, f: Field | undefined, rows: Row[]): Lane[] {
  if (!f) return [{ key: "", name: "All records" }];
  const none = { key: NONE, name: "No value" };
  if (f.type === "singleSelect") return [...(f.options.choices ?? []).map(c => ({ key: c.id, name: c.name, color: c.color })), none];
  if (f.type === "user") return [...client.members.map(m => ({ key: m.id, name: m.name })), none];
  const seen = new Map<string, string>();
  for (const r of rows) for (const x of (valueOf(f, r) as { id: number; t?: string }[] | undefined) ?? []) seen.set(String(x.id), x.t || `Record ${x.id}`);
  return [...[...seen].map(([key, name]) => ({ key, name })).sort((a, b) => a.name.localeCompare(b.name)), none];
}

export default function TimelineView(props: Props) {
  useBase(props.client);
  const view = props.client.view(props.view.id) ?? props.view;
  const options = dateFields(props.client, view.tableId);
  const start = options.find(f => f.id === view.config.dateFieldId);
  if (!start) return <DateSetup client={props.client} view={view} icon="timeline" title="Plan records on a timeline" text="Choose the date field where each bar starts." />;
  return <TimelineBody {...props} view={view} start={start} options={options} />;
}

function TimelineBody({ client, view, search, onExpand, start, options }: Props & { start: Field; options: Field[] }) {
  const tableId = view.tableId;
  const cfg = view.config;
  const all = client.fields(tableId);
  const end = options.find(f => f.id === cfg.endDateFieldId && f.id !== start.id);
  const dur = end ? undefined : all.find(f => f.id === cfg.durationFieldId && isNumberField(f));
  const laneField = all.find(f => f.id === cfg.laneFieldId && LANE_TYPES.has(f.type));
  const scale: Scale = cfg.timelineScale ?? "week";
  const px = PX_PER_DAY[scale];
  const span = WINDOW_DAYS[scale];
  const [center, setCenter] = useState<Day>(() => localDay());
  const [jump, setJump] = useState(0);
  const [collapsed, setCollapsed] = useState<Set<string>>(new Set());
  const [settings, setSettings] = useState<HTMLElement | null>(null);
  const [drag, setDragState] = useState<Drag | null>(null);
  const dragRef = useRef<Drag | null>(null);
  const scroller = useRef<HTMLDivElement>(null);
  const shift = useRef(0);
  const from = addDays(center, -Math.floor(span / 2));
  const to = addDays(from, span - 1);
  const setDrag = (d: Drag | null) => {
    dragRef.current = d;
    setDragState(d);
  };

  useEffect(() => {
    client.setViewRange(view.id, from, to, search);
  }, [client, view.id, from, to, search]);

  // Put today a third of the way in when the view opens, the scale changes or Today is clicked.
  useLayoutEffect(() => {
    const el = scroller.current;
    if (el) el.scrollLeft = Math.max(0, dayToX(localDay(), from, px) - el.clientWidth / 3);
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [scale, jump]);

  // After the window moved, keep the same dates under the viewport.
  useLayoutEffect(() => {
    const el = scroller.current;
    if (el && shift.current) {
      el.scrollLeft += shift.current;
      shift.current = 0;
    }
  }, [from]);

  const st = client.viewState(view.id);
  const ids = st?.ids ?? [];
  useEffect(() => {
    client.ensureRows(tableId, ids);
  });

  const editable = client.writable && !COMPUTED_TYPES.has(start.type) && (!end || !COMPUTED_TYPES.has(end.type));
  const rows = ids.map(id => client.row(tableId, id)).filter((r): r is Row => !!r);
  const unscheduled = client.unscheduledIds(view.id).map(id => client.row(tableId, id)).filter((r): r is Row => !!r);
  const lanes = lanesFor(client, laneField, [...rows, ...unscheduled]);
  const bars: Bar[] = [];
  for (const r of rows) {
    const s = spanOf(valueOf(start, r), end ? valueOf(end, r) : undefined, dur ? valueOf(dur, r) : undefined);
    if (!s) continue;
    const title = primaryText(client, tableId, r) || "Unnamed record";
    for (const lane of laneKeys(laneField, r)) bars.push({ id: r.id, title, lane, ...s });
  }

  const preview = (b: Bar): Span => {
    if (!drag || drag.id !== b.id || drag.lane !== b.lane || drag.mode === "place") return b;
    const days = Math.round(drag.dx / px);
    if (drag.mode === "move") return { start: addDays(b.start, days), end: addDays(b.end, days) };
    if (drag.mode === "start") {
      const s = addDays(b.start, days);
      return { start: s <= b.end ? s : b.end, end: b.end };
    }
    const e = addDays(b.end, days);
    return { start: b.start, end: e >= b.start ? e : b.start };
  };

  const write = (id: number, next: Span, extra: Cells = {}) => {
    const row = client.row(tableId, id);
    if (!row) return;
    const cells: Cells = { ...extra, [start.id]: withDay(valueOf(start, row), next.start, !!start.options.includeTime) };
    if (end) {
      if (!isEmpty(valueOf(end, row)) || next.end !== next.start) cells[end.id] = withDay(valueOf(end, row), next.end, !!end.options.includeTime);
    } else if (dur && !COMPUTED_TYPES.has(dur.type)) cells[dur.id] = diffDays(next.start, next.end) + 1;
    // Records placed from the unscheduled row are not in this view's ids yet; own writes are not echoed back.
    void client.updateCells(tableId, [{ id, cells }], { label: "Reschedule" }).then(() => {
      if (!ids.includes(id)) void client.queryView(view.id, search);
    });
  };

  /** Cells that move a record from one lane to another; null when the lane field cannot be reassigned. */
  const laneCells = (row: Row, fromLane: string, toLane: string): Cells | null => {
    if (!laneField || fromLane === toLane) return null;
    if (laneField.type === "singleSelect" || (laneField.type === "user" && !laneField.options.multiple)) return { [laneField.id]: toLane === NONE ? null : toLane };
    if (laneField.type === "user") {
      const cur = ((valueOf(laneField, row) as string[] | undefined) ?? []).filter(x => x !== fromLane);
      return { [laneField.id]: toLane === NONE ? cur : [...new Set([...cur, toLane])] };
    }
    return null; // link lanes do not reassign
  };

  const begin = (e: React.PointerEvent, id: number, lane: string, mode: Drag["mode"]) => {
    if (!editable || e.button !== 0) return;
    e.preventDefault();
    e.stopPropagation();
    setDrag({ id, lane, mode, x0: e.clientX, dx: 0, overLane: lane });
  };

  useEffect(() => {
    if (!drag) return;
    const move = (e: PointerEvent) => {
      const d = dragRef.current;
      if (!d) return;
      const el = document.elementFromPoint(e.clientX, e.clientY)?.closest("[data-lane]");
      setDrag({ ...d, dx: e.clientX - d.x0, overLane: el?.getAttribute("data-lane") ?? d.overLane });
    };
    const up = (e: PointerEvent) => {
      const d = dragRef.current;
      setDrag(null);
      if (!d) return;
      const row = client.row(tableId, d.id);
      if (!row) return;
      const lc = laneCells(row, d.lane, d.overLane);
      if (d.mode === "place") {
        const el = scroller.current;
        if (!el) return;
        const x = e.clientX - el.getBoundingClientRect().left + el.scrollLeft - LEFT_W;
        if (x < 0) return;
        const day = xToDay(x, from, px);
        return write(d.id, { start: day, end: day }, lc ?? {});
      }
      const moved = Math.abs(e.clientX - d.x0) > 3 || d.overLane !== d.lane;
      if (!moved) {
        if (d.mode === "move") onExpand(d.id);
        return;
      }
      const b = bars.find(x => x.id === d.id && x.lane === d.lane);
      if (!b) return;
      const next = preview(b);
      const laneChange = d.mode === "move" ? lc : null;
      if (next.start === b.start && next.end === b.end && !laneChange) return;
      write(d.id, next, laneChange ?? {});
    };
    window.addEventListener("pointermove", move);
    window.addEventListener("pointerup", up);
    return () => {
      window.removeEventListener("pointermove", move);
      window.removeEventListener("pointerup", up);
    };
  });

  const onScroll = () => {
    const el = scroller.current;
    if (!el || shift.current) return;
    const width = span * px;
    const edge = width * 0.15;
    const left = el.scrollLeft;
    const nearStart = left < edge;
    const nearEnd = left + el.clientWidth - LEFT_W > width - edge;
    if (!nearStart && !nearEnd) return;
    const days = Math.round(span / 3) * (nearStart ? -1 : 1);
    shift.current = -days * px;
    setCenter(c => addDays(c, days));
  };

  const toggleLane = (key: string) =>
    setCollapsed(prev => {
      const next = new Set(prev);
      if (next.has(key)) next.delete(key);
      else next.add(key);
      return next;
    });

  const today = localDay();
  const ticks = axisTicks(from, to, scale);
  const width = span * px;
  const ro = !client.writable;
  const fieldSelect = (label: string, value: string, list: Field[], onChange: (v: string) => void, none?: string, disabled = false) => (
    <>
      <label className="field-label">{label}</label>
      <select className="input" disabled={ro || disabled} value={value} onChange={e => onChange(e.target.value)}>
        {none !== undefined && <option value="">{none}</option>}
        {list.map(f => <option key={f.id} value={f.id}>{f.name}</option>)}
      </select>
    </>
  );

  return (
    <div className="tl">
      <div className="kb-toolbar cal-toolbar">
        <div className="cal-nav">
          <Button small onClick={() => { shift.current = 0; setCenter(localDay()); setJump(j => j + 1); }}>Today</Button>
          <strong className="cal-title-text">{monthLabel(center)}</strong>
          {st?.loading && <Spinner size={14} />}
        </div>
        <div className="cal-nav">
          <div className="seg">
            {(["day", "week", "month"] as const).map(s => (
              <button key={s} className={"seg-btn" + (scale === s ? " active" : "")} onClick={() => { setCenter(localDay()); client.updateViewConfig(view.id, { timelineScale: s }); }}>{s[0]!.toUpperCase() + s.slice(1)}</button>
            ))}
          </div>
          <button className={"btn btn-sm btn-ghost" + (settings ? " active" : "")} onClick={e => setSettings(settings ? null : e.currentTarget)}><Icon name="settings" size={14} /> Settings</button>
        </div>
        {settings && (
          <Popover anchor={settings} onClose={() => setSettings(null)} width={280} align="end" className="kb-settings">
            {fieldSelect("Start date", start.id, options, v => client.updateViewConfig(view.id, { dateFieldId: v }))}
            {fieldSelect("End date", end?.id ?? "", options.filter(f => f.id !== start.id), v => client.updateViewConfig(view.id, { endDateFieldId: v || undefined }), "None")}
            {fieldSelect("Duration in days (without an end date)", dur?.id ?? "", all.filter(isNumberField), v => client.updateViewConfig(view.id, { durationFieldId: v || undefined }), "None", !!end)}
            {fieldSelect("Lanes", laneField?.id ?? "", all.filter(f => LANE_TYPES.has(f.type)), v => client.updateViewConfig(view.id, { laneFieldId: v || undefined }), "No lanes")}
          </Popover>
        )}
      </div>
      {st?.error ? (
        <Empty title="Could not load records">
          <div className="muted">{st.error}</div>
          <Button small onClick={() => client.queryView(view.id, search)}>Retry</Button>
        </Empty>
      ) : (
        <div className={"tl-scroll" + (drag ? " dragging" : "")} ref={scroller} onScroll={onScroll}>
          <div className="tl-canvas" style={{ width: LEFT_W + width }}>
            <div className="tl-axis">
              <div className="tl-corner">{laneField ? laneField.name : "Records"}</div>
              {ticks.map(t => <div key={t.day} className={"tl-tick" + (t.major ? " major" : "")} style={{ left: LEFT_W + dayToX(t.day, from, px) }}>{t.label}</div>)}
            </div>
            {lanes.map(l => {
              const laneBars = bars.filter(b => b.lane === l.key);
              const laneUn = unscheduled.filter(r => laneKeys(laneField, r).includes(l.key));
              if (l.key === NONE && !laneBars.length && !laneUn.length) return null;
              const packed = packRows(laneBars.flatMap(b => {
                const seg = clip(preview(b), from, to);
                return seg ? [{ ...seg, id: b.id, title: b.title }] : [];
              }));
              const rowsN = Math.max(1, ...packed.map(p => p.row + 1));
              const open = !collapsed.has(l.key);
              return (
                <section key={l.key} className={"tl-lane" + (drag && drag.overLane === l.key && drag.lane !== l.key ? " over" : "")} data-lane={l.key}>
                  <div className="tl-lane-head">
                    <button className="tl-lane-name" onClick={() => toggleLane(l.key)}>
                      <Icon name="chevron" size={14} className={open ? "" : "tl-closed"} />
                      {l.color && <span className="tl-dot" style={{ background: l.color }} />}
                      <span className="grow">{l.name}</span>
                      <span className="kb-count">{laneBars.length}</span>
                    </button>
                  </div>
                  {open && (
                    <div className="tl-lane-body" style={{ height: rowsN * ROW_H + (laneUn.length ? ROW_H : 0) + 6 }}>
                      <div className="tl-gutter" />
                      {today >= from && today <= to && <div className="tl-today" style={{ left: LEFT_W + dayToX(today, from, px) + px / 2 }} />}
                      {packed.map(p => {
                        const w = (diffDays(p.start, p.end) + 1) * px - 2;
                        return (
                          <div
                            key={p.id}
                            className={"tl-bar" + (drag?.id === p.id && drag.lane === l.key ? " dragging" : "") + (p.cutStart ? " cut-start" : "") + (p.cutEnd ? " cut-end" : "")}
                            style={{ left: LEFT_W + dayToX(p.start, from, px), width: Math.max(w, 6), top: 3 + p.row * ROW_H, background: l.color }}
                            title={p.title}
                            data-id={p.id}
                            onPointerDown={e => begin(e, p.id, l.key, "move")}
                            onClick={() => !editable && onExpand(p.id)}
                          >
                            {editable && !p.cutStart && <span className="tl-handle start" onPointerDown={e => begin(e, p.id, l.key, "start")} />}
                            <span className={"tl-label" + (w < 80 ? " outside" : "")}>{p.title}</span>
                            {editable && !p.cutEnd && <span className="tl-handle end" onPointerDown={e => begin(e, p.id, l.key, "end")} />}
                          </div>
                        );
                      })}
                      {laneUn.length > 0 && (
                        <div className="tl-unscheduled" style={{ top: 3 + rowsN * ROW_H }}>
                          <div className="tl-unscheduled-inner">
                            <span className="muted small">Unscheduled</span>
                            {laneUn.slice(0, 20).map(r => (
                              <span key={r.id} className="tl-chip" onPointerDown={e => begin(e, r.id, l.key, "place")} onClick={() => !editable && onExpand(r.id)}>{primaryText(client, tableId, r) || "Unnamed record"}</span>
                            ))}
                          </div>
                        </div>
                      )}
                    </div>
                  )}
                </section>
              );
            })}
          </div>
        </div>
      )}
    </div>
  );
}
```

```ts
  kind: "rf-group";
  label: string;
  count: number;
  level: number;
  collapsed: boolean;
}

export type GroupHeaderCell = CustomCell<GroupHeaderData>;

/** First cell of a group header row: chevron, group value and record count, indented by level. */
export const groupHeaderRenderer: CustomRenderer<GroupHeaderCell> = {
  kind: GridCellKind.Custom,
  isMatch: (c): c is GroupHeaderCell => (c.data as GroupHeaderData | undefined)?.kind === "rf-group",
  draw: (args, cell) => {
    const { ctx, rect, theme } = args;
    const x0 = rect.x + theme.cellHorizontalPadding + cell.data.level * 14;
    const cy = rect.y + rect.height / 2;
    ctx.save();
    ctx.beginPath();
    ctx.rect(rect.x, rect.y, rect.width, rect.height);
    ctx.clip();
    ctx.strokeStyle = theme.textMedium;
    ctx.lineWidth = 1.5;
    ctx.beginPath();
    if (cell.data.collapsed) {
      ctx.moveTo(x0 + 2, cy - 4);
      ctx.lineTo(x0 + 6, cy);
      ctx.lineTo(x0 + 2, cy + 4);
    } else {
      ctx.moveTo(x0, cy - 2);
      ctx.lineTo(x0 + 4, cy + 2);
      ctx.lineTo(x0 + 8, cy - 2);
    }
    ctx.stroke();
    ctx.textBaseline = "middle";
    ctx.font = `600 13px ${theme.fontFamily}`;
    ctx.fillStyle = theme.textDark;
    ctx.fillText(cell.data.label, x0 + 16, cy + 0.5);
    const w = ctx.measureText(cell.data.label).width;
```

```ts
export function toViewConfig(t: TableCtx, v: ViewOptionsInput): ViewConfig {
  const config: ViewConfig = {};
  const id = (key: string) => fieldOf(t.fields, key, t.table.name).id;
  if (v.filter) config.filters = toFilterSpec(t, v.filter) ?? { conjunction: "and", conditions: [] };
  if (v.sort) config.sorts = toSorts(t, v.sort) ?? [];
  if (v.hiddenFields) config.hidden = v.hiddenFields.map(id);
  if (typeof v.groupBy === "string") config.groupFieldId = id(v.groupBy);
  else if (v.groupBy) config.groups = v.groupBy.map(g => ({ fieldId: id(g.field), dir: g.direction ?? "asc" }));
  if (v.dateField) config.dateFieldId = id(v.dateField);
```
