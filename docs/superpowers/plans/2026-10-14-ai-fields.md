# AI Fields Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let table fields be filled by a model (the workspace's own Anthropic or OpenAI-compatible key, or Workers AI on Cloudflare), with background generation inside each base's Durable Object, an "AI generate" automation step, MCP and REST support, and UI in settings, the field dialog, the grid and the record view.

**Architecture:** AI settings live in `options.ai` of ordinary fields (text, long text, single select, multiple select, number, date, checkbox). The base DO keeps per-cell state and a queue in SQLite (`_ai_cells`, `_ai_queue`, `_ai_batches`), fills the queue inside each write's transaction through the existing `onWrite` hook, and works through it from its alarm with at most 6 model calls at once. Services and usage live in D1 (`workspace_ai`, `ai_usage`), keys encrypted with `SECRET_KEY`.

**Tech Stack:** TypeScript, Hono, Cloudflare Workers and Durable Objects (SQLite), D1, R2, React 19, Glide Data Grid 6, Vitest with `@cloudflare/vitest-pool-workers`, MCP SDK, zod.

**Spec:** `docs/superpowers/specs/2026-10-14-ai-fields-design.md`

## Global Constraints

- No Chinese in code or comments. No em dash anywhere (code, docs, UI strings). Plain text in docs is not hard-wrapped.
- One commit per finished task on branch `ai-fields`, short message, no Co-Authored-By line. No push, no merge.
- Output types: `text`, `longText`, `singleSelect`, `multiSelect`, `number`, `date`, `checkbox`. Other field types drop `options.ai`.
- Limits: 20 AI fields per table, 10 services per workspace, prompt 8,000 characters stored and 32,000 expanded, 4 images of 5 MB from at most 2 attachment fields, 6 calls at once per base, 60 seconds per call, 25 seconds of AI work per alarm, 8,000 output tokens per call, debounce 2 seconds, retries after 10 s, 1 min, 5 min (`Retry-After` up to 5 min respected).
- Workers AI default models: text `@cf/meta/llama-3.3-70b-instruct-fp8-fast`, images `@cf/meta/llama-3.2-11b-vision-instruct`. Service id `workers`, offered only when the `AI` binding exists. `AI_WORKERS_MONTHLY_CALLS` unset means no limit.
- `base_url` of OpenAI-compatible services: `https://`, or `http://` only with `AUTOMATION_ALLOW_PRIVATE=true`; private addresses refused unless that is set; redirects not followed.
- Only owners manage and test services; editors and viewers see names, kinds and models. Editors generate, stop and preview; viewers only see values and states.
- Imports (CSV, Airtable), templates and background jobs never queue AI cells.
- AI writes use the actor `{ userId: "ai", name: "AI" }`, fire automation record triggers, and are broadcast like any write.
- The DeepSeek key used for QA lives only in the scratchpad (`scratchpad/qa/deepseek.txt`); never in the repo, docs or test files.

## Review Focus

1. A user types into an AI cell while its generation is running: the typed value must win, the late answer must be dropped and the cell must show "edited". (Task 5 test "a late answer does not overwrite a value typed during the call".)
2. Prompts containing literal braces such as `Return JSON like {"a": 1}`: only `{Field name}` references that match a field may be converted; other braces stay text and the prompt must not be rejected. (Task 1 test "braces that are not field names stay text".)
3. Bulk paste of 1,000 rows into a table with an auto-updating AI field: one queue entry per row and field, no model call inside the write, and the write must stay fast. (Task 4 test "a 1,000 row paste queues 1,000 entries in one write" and the Task 12 bench.)
4. A service deleted or a key rejected while 500 cells are queued: entries must wait without spinning the alarm every few milliseconds, and resume when fixed. (Task 5 tests "entries of a rejected key wait 10 minutes" and "a missing service postpones instead of failing".)
5. A reasoning model that spends its whole token budget thinking and returns empty content: the cell must show "The answer was cut off", not an empty success. (Task 2 test "empty content with finish_reason length is cut off".)

```ts
// AI fields shared by the Durable Object, the routes, MCP and the editor: types, limits,
// prompt references, the instruction per output type, answer parsing and prompt expansion.
import type { Field, FieldType } from "./types";
import { parseDate, parseNumber } from "./cells";

export const AI_OUTPUT_TYPES = ["text", "longText", "singleSelect", "multiSelect", "number", "date", "checkbox"] as const;
export type AiOutputType = (typeof AI_OUTPUT_TYPES)[number];
export const isAiOutputType = (t: FieldType): t is AiOutputType => (AI_OUTPUT_TYPES as readonly string[]).includes(t);

export interface AiConfig {
  serviceId: string;
  model?: string;
  prompt: string;
  imageFieldIds?: string[];
  autoUpdate: boolean;
  template?: string;
}

export type AiServiceKind = "anthropic" | "openai" | "workers";

export interface AiServiceInfo {
  id: string;
  name: string;
  kind: AiServiceKind;
  model: string;
  baseUrl?: string | null;
  last4?: string | null;
  keyRejected: boolean;
  /** Calls this month. */
  calls: number;
}

export type AiCellStateName = "queued" | "running" | "error" | "edited";
export interface AiCellState {
  s: AiCellStateName;
  e?: string;
}

export interface AiProgress {
  tableId: string;
  fieldId: string;
  queued: number;
  done: number;
  total: number;
}

export const AI_LIMITS = {
  fieldsPerTable: 20,
  services: 10,
  promptChars: 8000,
  expandedChars: 32_000,
  images: 4,
  imageBytes: 5 * 1024 * 1024,
  imageFields: 2,
  concurrency: 6,
  callTimeout: 60_000,
  alarmBudget: 25_000,
  outputTokens: 8000,
  debounce: 2000,
  retryDelays: [10_000, 60_000, 300_000],
  maxRetryAfter: 300_000,
  /** Entries that cannot run now (missing service, rejected key, ended trial) look again after this. */
  pause: 600_000,
} as const;

export const WORKERS_TEXT_MODEL = "@cf/meta/llama-3.3-70b-instruct-fp8-fast";
export const WORKERS_IMAGE_MODEL = "@cf/meta/llama-3.2-11b-vision-instruct";
export const AI_ACTOR = { userId: "ai", name: "AI" };

/** Starting points in the field dialog; "{Field}" becomes the table's primary field. */
export const AI_TEMPLATES: { id: string; label: string; output: AiOutputType; prompt: string; choices?: string[] }[] = [
  { id: "summarize", label: "Summarize", output: "longText", prompt: "Summarize {Field} in one or two sentences." },
  { id: "translate", label: "Translate", output: "longText", prompt: "Translate {Field} into English." },
  { id: "extract", label: "Extract information", output: "text", prompt: "From {Field}, extract the company name." },
  { id: "classify", label: "Classify", output: "singleSelect", prompt: "Classify {Field} into one of the options.", choices: ["Question", "Bug", "Feature request"] },
  { id: "tag", label: "Tag", output: "multiSelect", prompt: "Pick every tag that fits {Field}.", choices: ["Pricing", "Support", "Product"] },

const REF = /\{([^{}\n]{1,100})\}/g;
const ID_REF = /\{(fld[A-Za-z0-9_]{3,40})\}/g;

export function promptRefIds(stored: string): string[] {
  const out: string[] = [];
  for (const m of stored.matchAll(ID_REF)) if (!out.includes(m[1])) out.push(m[1]);
  return out;
}

/** {Field name} to {fieldId}; braces that name no field stay as they are. */
export function promptToStored(text: string, fields: { id: string; name: string }[]): string {
  return text.replace(REF, (all, inner: string) => {
    const key = inner.trim();
    const f = fields.find(x => x.name === key) ?? fields.find(x => x.name.toLowerCase() === key.toLowerCase()) ?? fields.find(x => x.id === key);
    return f ? `{${f.id}}` : all;
  });
}

export function promptToDisplay(stored: string, fields: { id: string; name: string }[]): string {
  return stored.replace(ID_REF, (all, id: string) => {
    const f = fields.find(x => x.id === id);
    return f ? `{${f.name}}` : all;
  });
}

export function aiDeps(f: Pick<Field, "options">): string[] {
  const ai = f.options.ai;
  return ai ? [...new Set([...promptRefIds(ai.prompt), ...(ai.imageFieldIds ?? [])])] : [];
}

const names = (f: Pick<Field, "options">) => (f.options.choices ?? []).map(c => c.name).join(" | ");

export function systemInstruction(f: Pick<Field, "type" | "options">): string {
  switch (f.type) {
    case "singleSelect":
      return `Answer with exactly one of these options and nothing else: ${names(f)}`;
    case "multiSelect":
      return `Answer with zero or more of these options, separated by commas, and nothing else: ${names(f)}`;
    case "number":
      return "Answer with a single number only.";
    case "date":
      return "Answer with a single date in the form YYYY-MM-DD only.";
    case "checkbox":
      return "Answer with yes or no only.";
    default:
      return "Answer with the result only, without preamble.";
  }
}

/** Trims quotes, Markdown emphasis, code fences and a final period. */
function clean(raw: string): string {
  let s = raw.trim().replace(/^```[a-z]*\s*|\s*```$/g, "").trim();
  for (let i = 0; i < 3; i++) s = s.replace(/^(\*\*|__|\*|_|"|'|`)(.*)\1$/s, "$2").trim();
  return s.replace(/\.$/, "").trim();
}

const choiceByName = (f: Pick<Field, "options">, name: string) => {
  const n = name.trim().toLowerCase();
  return (f.options.choices ?? []).find(c => c.name.toLowerCase() === n);
};

export function parseAnswer(f: Pick<Field, "type" | "options">, raw: string): { ok: true; value: unknown } | { ok: false; error: string } {
  const bad = (what: string) => ({ ok: false as const, error: `The answer "${raw.trim().slice(0, 200)}" is not ${what}` });
  switch (f.type) {
    case "text":
      return { ok: true, value: clean(raw).split(/\r?\n/)[0].trim() || null };
    case "longText": {
      const s = raw.trim().replace(/^```[a-z]*\s*|\s*```$/g, "").trim();
      return { ok: true, value: s || null };
    }
    case "singleSelect": {
      const c = choiceByName(f, clean(raw));
      return c ? { ok: true, value: c.id } : bad("one of the options");
    }
    case "multiSelect": {
      const s = clean(raw);
      if (!s || /^(none|nothing|n\/a)$/i.test(s)) return { ok: true, value: null };
      const ids: string[] = [];
      for (const part of s.split(/[,;\n]/).map(clean).filter(Boolean)) {
        const c = choiceByName(f, part);
        if (!c) return bad("one of the options");
        if (!ids.includes(c.id)) ids.push(c.id);
      }
      return { ok: true, value: ids };
    }
    case "number": {
      const m = /-?\d[\d,]*(\.\d+)?|-?\.\d+/.exec(clean(raw));
      const n = m ? parseNumber(m[0].replace(/,/g, "")) : null;
      return n === null ? bad("a number") : { ok: true, value: n };
    }
    case "date": {
      const s = clean(raw);
      const iso = /\d{4}-\d{2}-\d{2}(T[\d:.]+Z?)?/.exec(s)?.[0];
      const d = parseDate(iso ?? s, !!f.options.includeTime);
      return d ? { ok: true, value: d } : bad("a date");
    }
    case "checkbox": {
      const s = clean(raw).toLowerCase();
      if (/^(yes|true|1|y)$/.test(s)) return { ok: true, value: true };
      if (/^(no|false|0|n)$/.test(s)) return { ok: true, value: null };
      return bad("yes or no");
    }
    default:
      return { ok: false, error: "This field type cannot hold AI answers" };
  }
}

export function expandPrompt(stored: string, text: (fieldId: string) => string | null): { text: string; cut: boolean } {
  const out = stored.replace(ID_REF, (all, id: string) => text(id) ?? all);
  return out.length > AI_LIMITS.expandedChars ? { text: out.slice(0, AI_LIMITS.expandedChars), cut: true } : { text: out, cut: false };
}

export async function inputHash(v: unknown): Promise<string> {
  const buf = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(JSON.stringify(v)));
  return [...new Uint8Array(buf)].map(b => b.toString(16).padStart(2, "0")).join("");
}

/** Shape checks for options.ai; references are checked against the schema by the store. */
export function normalizeAi(raw: unknown): AiConfig | undefined {
  if (raw === undefined || raw === null) return undefined;
  if (typeof raw !== "object" || Array.isArray(raw)) throw new Error("Invalid AI settings");
  const o = raw as Record<string, unknown>;
  const serviceId = typeof o.serviceId === "string" ? o.serviceId.trim() : "";
  if (!serviceId) throw new Error("Choose an AI service");
  const prompt = typeof o.prompt === "string" ? o.prompt : "";
  if (!prompt.trim()) throw new Error("Write a prompt");
  if (prompt.length > AI_LIMITS.promptChars) throw new Error("A prompt can have at most 8,000 characters");
  const out: AiConfig = { serviceId, prompt, autoUpdate: o.autoUpdate !== false };
  if (typeof o.model === "string" && o.model.trim()) out.model = o.model.trim().slice(0, 200);
  if (o.imageFieldIds !== undefined) {
    if (!Array.isArray(o.imageFieldIds) || o.imageFieldIds.some(x => typeof x !== "string")) throw new Error("Invalid image fields");
    if (o.imageFieldIds.length > AI_LIMITS.imageFields) throw new Error("Choose at most 2 image fields");
    if (o.imageFieldIds.length) out.imageFieldIds = [...new Set(o.imageFieldIds as string[])];
  }
  if (typeof o.template === "string" && o.template) out.template = o.template.slice(0, 40);
  return out;
}
```

```ts
// src/worker/ai/providers.ts
// Calls a model: Anthropic Messages, OpenAI-compatible chat completions, or the Workers AI binding.
// Errors come back as AiError with a kind the engine acts on: retry later, key rejected, or fail the cell.
import { AI_LIMITS, WORKERS_IMAGE_MODEL, type AiServiceKind } from "../../shared/ai";
import { checkUrl, readLimited } from "../auto/http";

export interface ModelService {
  id: string;
  kind: AiServiceKind;
  baseUrl?: string | null;
  model: string;
  key?: string;
}

export interface ModelImage {
  type: string;
  /** Base64 without the data: prefix. */
  data: string;
}

export interface ModelRequest {
  system: string;
  prompt: string;
  images: ModelImage[];
  /** Overrides the service's default model. */
  model?: string;
}

export interface WorkersAi {
  run(model: string, input: unknown): Promise<unknown>;
}

export interface AiDeps {
  fetchFn?: typeof fetch;
  ai?: WorkersAi;
  allowPrivate: boolean;
  timeoutMs: number;
}

export class AiError extends Error {
  constructor(message: string, readonly kind: "retry" | "auth" | "fail", readonly retryAfter?: number) {
    super(message);
  }
}

const CUT = "The answer was cut off";
const MAX_READ = 1024 * 1024;

function retryAfter(h: string | null): number | undefined {
  if (!h) return undefined;
  const s = Number(h);
  const ms = Number.isFinite(s) ? s * 1000 : Date.parse(h) - Date.now();
  return Number.isFinite(ms) && ms > 0 ? Math.min(ms, AI_LIMITS.maxRetryAfter) : undefined;
}

function errorText(body: string): string {
  try {
    const j = JSON.parse(body);
    const m = j?.error?.message ?? j?.message ?? j?.error;
    if (typeof m === "string") return m.slice(0, 300);
  } catch {
    // Not JSON.
  }
  return body.slice(0, 300);
}

async function post(url: string, headers: Record<string, string>, body: unknown, d: AiDeps): Promise<unknown> {
  let u: URL;
  try {
    u = checkUrl(url, d.allowPrivate);
  } catch (e) {
    throw new AiError(e instanceof Error ? e.message : String(e), "fail");
  }
  if (u.protocol === "http:" && !d.allowPrivate) throw new AiError("The service address must start with https://", "fail");
  const ctrl = new AbortController();
  const timer = setTimeout(() => ctrl.abort(), d.timeoutMs);
  try {
    let res: Response;
    try {
      res = await (d.fetchFn ?? fetch)(u.toString(), { method: "POST", headers: { "content-type": "application/json", ...headers }, body: JSON.stringify(body), redirect: "manual", signal: ctrl.signal });
    } catch (e) {
      throw new AiError(ctrl.signal.aborted ? "The service did not answer in time" : `Could not reach the service: ${e instanceof Error ? e.message : String(e)}`, "retry");
    }
    if (res.headers.get("x-rowflare-blocked") === "private") throw new AiError("Requests to private network addresses are not allowed", "fail");
    const text = await readLimited(res, MAX_READ).catch(e => {
      throw new AiError(`The service stopped answering: ${e instanceof Error ? e.message : String(e)}`, "retry");
    });
    if (res.status === 401 || res.status === 403) throw new AiError("The key was rejected", "auth");
    if (res.status === 429 || res.status >= 500) throw new AiError(`The service answered ${res.status}: ${errorText(text)}`, "retry", retryAfter(res.headers.get("retry-after")));
    if (res.status >= 300) throw new AiError(`The service answered ${res.status}: ${errorText(text)}`, "fail");
    try {
      return JSON.parse(text);
    } catch {
      throw new AiError("The service sent an answer that is not JSON", "fail");
    }
  } finally {
    clearTimeout(timer);
  }
}

async function openai(s: ModelService, r: ModelRequest, d: AiDeps): Promise<string> {
  const base = (s.baseUrl ?? "").replace(/\/+$/, "");
  const content = r.images.length ? [{ type: "text", text: r.prompt }, ...r.images.map(i => ({ type: "image_url", image_url: { url: `data:${i.type};base64,${i.data}` } }))] : r.prompt;
  const j = (await post(`${base}/chat/completions`, s.key ? { Authorization: `Bearer ${s.key}` } : {}, { model: r.model || s.model, max_tokens: AI_LIMITS.outputTokens, messages: [{ role: "system", content: r.system }, { role: "user", content }] }, d)) as {
    choices?: { message?: { content?: unknown }; finish_reason?: string }[];
  };
  const choice = j.choices?.[0];
  const c = choice?.message?.content;
  const text = typeof c === "string" ? c : Array.isArray(c) ? c.map(p => (typeof p?.text === "string" ? p.text : "")).join("") : "";
  if (!text.trim()) throw new AiError(choice?.finish_reason === "length" ? CUT : "The service sent an empty answer", "fail");
  return text;
}

async function anthropic(s: ModelService, r: ModelRequest, d: AiDeps): Promise<string> {
  const content = [...r.images.map(i => ({ type: "image", source: { type: "base64", media_type: i.type, data: i.data } })), { type: "text", text: r.prompt }];
  const j = (await post("https://api.anthropic.com/v1/messages", { "x-api-key": s.key ?? "", "anthropic-version": "2023-06-01" }, { model: r.model || s.model, max_tokens: AI_LIMITS.outputTokens, system: r.system, messages: [{ role: "user", content }] }, d)) as {
    content?: { type: string; text?: string }[];
    stop_reason?: string;
  };
  const text = (j.content ?? []).filter(b => b.type === "text").map(b => b.text ?? "").join("");
  if (!text.trim()) throw new AiError(j.stop_reason === "max_tokens" ? CUT : "The service sent an empty answer", "fail");
  return text;
}

async function workers(s: ModelService, r: ModelRequest, d: AiDeps): Promise<string> {
  if (!d.ai) throw new AiError("Workers AI is not available on this server", "fail");
  const image = r.images[0];
  const model = image ? WORKERS_IMAGE_MODEL : r.model || s.model;
  const input: Record<string, unknown> = { messages: [{ role: "system", content: r.system }, { role: "user", content: r.prompt }], max_tokens: AI_LIMITS.outputTokens };
  // The vision model takes one image as bytes.
  if (image) input.image = [...Uint8Array.from(atob(image.data), ch => ch.charCodeAt(0))];
  let out: unknown;
  let timer: ReturnType<typeof setTimeout> | undefined;
  try {
    out = await Promise.race([d.ai.run(model, input), new Promise((_, rej) => (timer = setTimeout(() => rej(new AiError("Workers AI did not answer in time", "retry")), d.timeoutMs)))]);
  } catch (e) {
    if (e instanceof AiError) throw e;
    throw new AiError(`Workers AI failed: ${e instanceof Error ? e.message : String(e)}`, "retry");
  } finally {
    clearTimeout(timer);
  }
  const text = typeof (out as { response?: unknown })?.response === "string" ? (out as { response: string }).response : "";
  if (!text.trim()) throw new AiError("Workers AI sent an empty answer", "fail");
  return text;
}

export function callModel(s: ModelService, r: ModelRequest, d: AiDeps): Promise<string> {
  if (s.kind === "anthropic") return anthropic(s, r, d);
  if (s.kind === "workers") return workers(s, r, d);
  return openai(s, r, d);
}
```

```ts
  last4: string | null;

export const monthKey = (now: number) => new Date(now).toISOString().slice(0, 7);

async function usage(env: Env, ws: string, now: number): Promise<Map<string, number>> {
  const { results } = await env.DB.prepare("SELECT service_id, n FROM ai_usage WHERE workspace_id = ? AND month = ?").bind(ws, monthKey(now)).all<{ service_id: string; n: number }>();
  return new Map(results.map(r => [r.service_id, r.n]));
}

export async function listServices(env: Env, ws: string, now: number): Promise<AiServiceInfo[]> {
  const { results } = await env.DB.prepare("SELECT id, name, kind, base_url, model, last4, key_rejected_at FROM workspace_ai WHERE workspace_id = ? ORDER BY name").bind(ws).all<Row>();
  const used = await usage(env, ws, now);
  const out: AiServiceInfo[] = env.AI ? [{ id: WORKERS_SERVICE_ID, name: "Workers AI", kind: "workers", model: WORKERS_TEXT_MODEL, keyRejected: false, calls: used.get(WORKERS_SERVICE_ID) ?? 0 }] : [];
  for (const r of results) out.push({ id: r.id, name: r.name, kind: r.kind, model: r.model, baseUrl: r.base_url, last4: r.last4, keyRejected: !!r.key_rejected_at, calls: used.get(r.id) ?? 0 });
  return out;
}

export async function loadService(env: Env, ws: string, id: string): Promise<(ModelService & { keyRejected: boolean }) | null> {
  if (id === WORKERS_SERVICE_ID) return env.AI ? { id, kind: "workers", model: WORKERS_TEXT_MODEL, keyRejected: false } : null;
  const r = await env.DB.prepare("SELECT id, name, kind, base_url, model, secret_enc, last4, key_rejected_at FROM workspace_ai WHERE workspace_id = ? AND id = ?").bind(ws, id).first<Row>();
  if (!r) return null;
  const key = r.secret_enc && env.SECRET_KEY ? await decryptSecret(env.SECRET_KEY, r.secret_enc) : undefined;
  return { id: r.id, kind: r.kind, baseUrl: r.base_url, model: r.model, key, keyRejected: !!r.key_rejected_at };
}

export async function addUsage(env: Env, ws: string, counts: Map<string, number>, now: number): Promise<void> {
  const month = monthKey(now);
  const stmts = [...counts].filter(([, n]) => n > 0).map(([id, n]) => env.DB.prepare("INSERT INTO ai_usage (workspace_id, service_id, month, n) VALUES (?, ?, ?, ?) ON CONFLICT(workspace_id, service_id, month) DO UPDATE SET n = n + excluded.n").bind(ws, id, month, n));
  if (stmts.length) await env.DB.batch(stmts);
}

export async function workersLeft(env: Env, ws: string, now: number): Promise<number> {
  const limit = Number(env.AI_WORKERS_MONTHLY_CALLS);
  if (!env.AI_WORKERS_MONTHLY_CALLS || !Number.isFinite(limit) || limit <= 0) return Infinity;
  const used = (await usage(env, ws, now)).get(WORKERS_SERVICE_ID) ?? 0;
  return Math.max(0, limit - used);
}

export async function markRejected(env: Env, ws: string, id: string): Promise<void> {
  await env.DB.prepare("UPDATE workspace_ai SET key_rejected_at = ? WHERE workspace_id = ? AND id = ?").bind(Date.now(), ws, id).run();
}

export function aiDeps(env: Env, timeoutMs: number = AI_LIMITS.callTimeout): AiDeps {
  return { ai: env.AI, allowPrivate: env.AUTOMATION_ALLOW_PRIVATE === "true", timeoutMs };
```

```ts
    const ai = options.ai!;
    const fields = this.fieldMap(tableId);
    for (const id of promptRefIds(ai.prompt)) {
      if (id === selfId) throw new UserError("An AI field cannot refer to itself");
      if (!fields.has(id)) throw new UserError("The prompt refers to a field that does not exist");
    }
    for (const id of ai.imageFieldIds ?? []) if (fields.get(id)?.type !== "attachment") throw new UserError("Image fields must be attachment fields");
    const others = this.fieldsOf(tableId).filter(f => f.options.ai && f.id !== selfId);
    if (others.length >= AI_LIMITS.fieldsPerTable) throw new UserError("A table can have at most 20 AI fields");
    const seen = new Set<string>();
    const walk = (ids: string[]) => {
      for (const id of ids) {
        if (id === selfId) throw new UserError("AI fields cannot refer to each other in a circle");
        if (seen.has(id)) continue;
        seen.add(id);
        const f = this.c.fields.get(id);
        if (f?.options.ai) walk(aiDeps(f));
      }
    };
    walk(aiDeps({ options }));
  }

  aiFields(tableId: string): Field[] {
    return this.fieldsOf(tableId).filter(f => !!f.options.ai);
  }

  /** Why an AI field cannot run, or null. The service is checked by the engine. */
  aiBroken(f: Field): string | null {
    const ai = f.options.ai;
    if (!ai) return "Not an AI field";
    const fields = this.fieldMap(f.tableId);
    if (promptRefIds(ai.prompt).some(id => !fields.has(id))) return "The prompt refers to a deleted field";
    if ((ai.imageFieldIds ?? []).some(id => fields.get(id)?.type !== "attachment")) return "An image field was deleted or changed";
    return null;
  }

  /** A cell as text for prompts, the way the grid shows it. */
  displayText(tableId: string, row: Row, fieldId: string): string {
    const f = this.c.fields.get(fieldId);
    if (!f || f.tableId !== tableId) return "";
    const raw = f.type === "createdTime" ? row.createdAt : f.type === "modifiedTime" ? row.updatedAt : f.type === "autonumber" ? row.id : row.cells[f.id];
    return displayCell(f, raw, { userName: this.userName });
  }
```

```ts
// The AI cell queue and cell states, in the base's SQLite next to its tables.
// Writes queue cells inside their own transaction; the engine takes due entries from here.
import type { BaseStore, WriteInfo } from "../base/store";
import { AI_ACTOR, AI_LIMITS, aiDeps, type AiCellState, type AiCellStateName, type AiProgress } from "../../shared/ai";

export interface QueueEntry {
  tableId: string;
  fieldId: string;
  rowId: number;
  dueAt: number;
  tries: number;
  seq: number;
  manual: boolean;
}

interface EntryRow {
  table_id: string;
  field_id: string;
  row_id: number;
  due_at: number;
  tries: number;
  seq: number;
  manual: number;
}

const toEntry = (r: EntryRow): QueueEntry => ({ tableId: r.table_id, fieldId: r.field_id, rowId: r.row_id, dueAt: r.due_at, tries: r.tries, seq: r.seq, manual: !!r.manual });

export class AiQueue {
  private seq: number;
  /** Rows whose state changed since the engine last published them, by table. */
  readonly touched = new Map<string, Set<number>>();

  constructor(private store: BaseStore) {
    const sql = store.sql;
    sql.exec("CREATE TABLE IF NOT EXISTS _ai_cells (table_id TEXT NOT NULL, field_id TEXT NOT NULL, row_id INTEGER NOT NULL, state TEXT NOT NULL, error TEXT, input_hash TEXT, updated_at INTEGER NOT NULL, PRIMARY KEY (table_id, field_id, row_id))");
    sql.exec("CREATE TABLE IF NOT EXISTS _ai_queue (table_id TEXT NOT NULL, field_id TEXT NOT NULL, row_id INTEGER NOT NULL, due_at INTEGER NOT NULL, tries INTEGER NOT NULL DEFAULT 0, seq INTEGER NOT NULL, manual INTEGER NOT NULL DEFAULT 0, PRIMARY KEY (table_id, field_id, row_id))");
    sql.exec("CREATE INDEX IF NOT EXISTS _ai_queue_due ON _ai_queue (due_at)");
    sql.exec("CREATE TABLE IF NOT EXISTS _ai_batches (field_id TEXT PRIMARY KEY, table_id TEXT NOT NULL, total INTEGER NOT NULL, done INTEGER NOT NULL)");
    this.seq = store.one<{ s: number | null }>("SELECT max(seq) s FROM _ai_queue")?.s ?? 0;
  }

  private touch(tableId: string, rowId: number) {
    let s = this.touched.get(tableId);
    if (!s) this.touched.set(tableId, (s = new Set()));
    s.add(rowId);
  }

  /** Called by the store inside each write's transaction. */
  onWrite(w: WriteInfo, now: number) {
    const { store } = this;
    for (const d of w.deleted) this.forgetRows(d.tableId, d.ids);
    if (w.bulk) return;
    const byAi = w.actor.userId === AI_ACTOR.userId;
    const byTable = new Map<string, typeof w.rows>();
    for (const r of w.rows) byTable.set(r.tableId, [...(byTable.get(r.tableId) ?? []), r]);
    for (const [tableId, rows] of byTable) {
      const fields = store.aiFields(tableId);
      if (!fields.length) continue;
      for (const f of fields) {
        const deps = aiDeps(f);
        const auto = f.options.ai!.autoUpdate && !store.aiBroken(f);
        const queue: number[] = [];
        for (const r of rows) {
          if (r.changed.has(f.id) && !byAi) {
            this.markEdited(tableId, f.id, r.id, now);
            continue;
          }
          if (!auto) continue;
          if (!(r.isNew || deps.some(d => r.changed.has(d)))) continue;
          if (this.state(tableId, f.id, r.id)?.state === "edited") continue;
          queue.push(r.id);
        }
        if (queue.length) this.enqueue(tableId, f.id, queue, now + AI_LIMITS.debounce, false);
      }
    }
  }

  private markEdited(tableId: string, fieldId: string, rowId: number, now: number) {
    this.store.sql.exec("DELETE FROM _ai_queue WHERE table_id = ? AND field_id = ? AND row_id = ?", tableId, fieldId, rowId);
    this.store.sql.exec("INSERT INTO _ai_cells (table_id, field_id, row_id, state, error, input_hash, updated_at) VALUES (?, ?, ?, 'edited', NULL, NULL, ?) ON CONFLICT(table_id, field_id, row_id) DO UPDATE SET state = 'edited', error = NULL, updated_at = excluded.updated_at", tableId, fieldId, rowId, now);
    this.touch(tableId, rowId);
  }

  /** Queues cells (or moves their due time); returns how many were not queued before. */
  enqueue(tableId: string, fieldId: string, rowIds: number[], due: number, manual: boolean): number {
    const sql = this.store.sql;
    let added = 0;
    for (const id of rowIds) {
      const had = this.store.one("SELECT 1 x FROM _ai_queue WHERE table_id = ? AND field_id = ? AND row_id = ?", tableId, fieldId, id);
      sql.exec(
        "INSERT INTO _ai_queue (table_id, field_id, row_id, due_at, tries, seq, manual) VALUES (?, ?, ?, ?, 0, ?, ?) ON CONFLICT(table_id, field_id, row_id) DO UPDATE SET due_at = excluded.due_at, tries = 0, seq = excluded.seq, manual = max(manual, excluded.manual)",
        tableId, fieldId, id, due, ++this.seq, manual ? 1 : 0,
      );
      sql.exec("INSERT INTO _ai_cells (table_id, field_id, row_id, state, error, input_hash, updated_at) VALUES (?, ?, ?, 'queued', NULL, NULL, ?) ON CONFLICT(table_id, field_id, row_id) DO UPDATE SET state = 'queued', error = NULL, updated_at = excluded.updated_at", tableId, fieldId, id, Date.now());
      if (!had) added++;
      this.touch(tableId, id);
    }
    if (added) this.grow(tableId, fieldId, added);
    return added;
  }

  private grow(tableId: string, fieldId: string, n: number) {
    this.store.sql.exec("INSERT INTO _ai_batches (field_id, table_id, total, done) VALUES (?, ?, ?, 0) ON CONFLICT(field_id) DO UPDATE SET total = total + excluded.total", fieldId, tableId, n);
  }

  /** The whole column, or the rows never generated and still empty; one statement, so 100,000 rows take well under a second. */
  enqueueColumn(tableId: string, fieldId: string, missingOnly: boolean, now: number): number {
    const t = this.store.table(tableId);
    const sql = this.store.sql;
    const before = this.store.one<{ n: number }>("SELECT count(*) n FROM _ai_queue WHERE field_id = ?", fieldId)!.n;
    const where = missingOnly ? `WHERE json_extract(data, '$.${fieldId}') IS NULL AND id NOT IN (SELECT row_id FROM _ai_cells WHERE table_id = ? AND field_id = ?)` : "WHERE ? IS NOT NULL AND ? IS NOT NULL";
    const seq0 = this.seq;
    sql.exec(
      `INSERT INTO _ai_queue (table_id, field_id, row_id, due_at, tries, seq, manual) SELECT ?, ?, id, ?, 0, ? + id, 1 FROM ${t.phys} ${where} ON CONFLICT(table_id, field_id, row_id) DO UPDATE SET due_at = excluded.due_at, tries = 0, seq = excluded.seq, manual = 1`,
      tableId, fieldId, now, seq0, tableId, fieldId,
    );
    this.seq = this.store.one<{ s: number | null }>("SELECT max(seq) s FROM _ai_queue")?.s ?? this.seq;
    sql.exec(
      "INSERT INTO _ai_cells (table_id, field_id, row_id, state, error, input_hash, updated_at) SELECT table_id, field_id, row_id, 'queued', NULL, NULL, ? FROM _ai_queue WHERE field_id = ? AND seq > ? ON CONFLICT(table_id, field_id, row_id) DO UPDATE SET state = 'queued', error = NULL, updated_at = excluded.updated_at",
      now, fieldId, seq0,
    );
    const after = this.store.one<{ n: number }>("SELECT count(*) n FROM _ai_queue WHERE field_id = ?", fieldId)!.n;
    const queued = this.store.one<{ n: number }>("SELECT count(*) n FROM _ai_queue WHERE field_id = ? AND seq > ?", fieldId, seq0)!.n;
    if (after > before) this.grow(tableId, fieldId, after - before);
    this.store.sql.exec("UPDATE _ai_batches SET total = max(total, ?) WHERE field_id = ?", after, fieldId);
    return queued;
  }

  stop(fieldId: string) {
    const sql = this.store.sql;
    for (const r of this.store.all<{ table_id: string; row_id: number }>("SELECT table_id, row_id FROM _ai_queue WHERE field_id = ?", fieldId)) this.touch(r.table_id, r.row_id);
    sql.exec("DELETE FROM _ai_queue WHERE field_id = ?", fieldId);
    sql.exec("UPDATE _ai_cells SET state = 'done' WHERE field_id = ? AND state IN ('queued', 'running') AND input_hash IS NOT NULL", fieldId);
    sql.exec("DELETE FROM _ai_cells WHERE field_id = ? AND state IN ('queued', 'running')", fieldId);
    sql.exec("DELETE FROM _ai_batches WHERE field_id = ?", fieldId);
  }

  due(now: number, limit: number): QueueEntry[] {
    return this.store.all<EntryRow>("SELECT * FROM _ai_queue WHERE due_at <= ? ORDER BY due_at, seq LIMIT ?", now, limit).map(toEntry);
  }

  nextDue(): number | null {
    return this.store.one<{ t: number | null }>("SELECT min(due_at) t FROM _ai_queue")?.t ?? null;
  }

  get(tableId: string, fieldId: string, rowId: number): QueueEntry | undefined {
    const r = this.store.one<EntryRow>("SELECT * FROM _ai_queue WHERE table_id = ? AND field_id = ? AND row_id = ?", tableId, fieldId, rowId);
    return r && toEntry(r);
  }

  postpone(entries: QueueEntry[], until: number, tries?: (e: QueueEntry) => number) {
    for (const e of entries) this.store.sql.exec("UPDATE _ai_queue SET due_at = ?, tries = ? WHERE table_id = ? AND field_id = ? AND row_id = ? AND seq = ?", until, tries ? tries(e) : e.tries, e.tableId, e.fieldId, e.rowId, e.seq);
  }

  /** Removes an entry if it was not replaced since it was read, and counts it as done for the field's progress. */
  drop(e: QueueEntry) {
    const sql = this.store.sql;
    const gone = this.store.one<{ n: number }>("SELECT count(*) n FROM _ai_queue WHERE table_id = ? AND field_id = ? AND row_id = ? AND seq = ?", e.tableId, e.fieldId, e.rowId, e.seq)!.n;
    if (!gone) return;
    sql.exec("DELETE FROM _ai_queue WHERE table_id = ? AND field_id = ? AND row_id = ?", e.tableId, e.fieldId, e.rowId);
    sql.exec("UPDATE _ai_batches SET done = done + 1 WHERE field_id = ?", e.fieldId);
    if (!this.store.one("SELECT 1 x FROM _ai_queue WHERE field_id = ? LIMIT 1", e.fieldId)) sql.exec("DELETE FROM _ai_batches WHERE field_id = ?", e.fieldId);
  }

  setState(tableId: string, fieldId: string, rowId: number, state: AiCellStateName | "done", error: string | null = null, hash?: string) {
    this.store.sql.exec(
      "INSERT INTO _ai_cells (table_id, field_id, row_id, state, error, input_hash, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?) ON CONFLICT(table_id, field_id, row_id) DO UPDATE SET state = excluded.state, error = excluded.error, input_hash = coalesce(excluded.input_hash, input_hash), updated_at = excluded.updated_at",
      tableId, fieldId, rowId, state, error, hash ?? null, Date.now(),
    );
    this.touch(tableId, rowId);
  }

  state(tableId: string, fieldId: string, rowId: number): { state: string; hash: string | null } | undefined {
    const r = this.store.one<{ state: string; input_hash: string | null }>("SELECT state, input_hash FROM _ai_cells WHERE table_id = ? AND field_id = ? AND row_id = ?", tableId, fieldId, rowId);
    return r && { state: r.state, hash: r.input_hash };
  }

  states(tableId: string, ids: number[]): Map<number, Record<string, AiCellState>> {
    const out = new Map<number, Record<string, AiCellState>>();
    for (let i = 0; i < ids.length; i += 100) {
      const chunk = ids.slice(i, i + 100);
      const rows = this.store.all<{ row_id: number; field_id: string; state: string; error: string | null }>(
        `SELECT row_id, field_id, state, error FROM _ai_cells WHERE table_id = ? AND state <> 'done' AND row_id IN (${chunk.map(() => "?").join(",")})`,
        tableId, ...chunk,
      );
      for (const r of rows) {
        const m = out.get(r.row_id) ?? {};
        m[r.field_id] = r.error ? { s: r.state as AiCellStateName, e: r.error } : { s: r.state as AiCellStateName };
        out.set(r.row_id, m);
      }
    }
    return out;
  }

  progress(): AiProgress[] {
    return this.store
      .all<{ field_id: string; table_id: string; total: number; done: number; queued: number }>("SELECT b.field_id, b.table_id, b.total, b.done, (SELECT count(*) FROM _ai_queue q WHERE q.field_id = b.field_id) queued FROM _ai_batches b ORDER BY b.field_id")
      .map(r => ({ tableId: r.table_id, fieldId: r.field_id, queued: r.queued, done: r.done, total: r.total }));
  }

  status(tableId: string, fieldId: string) {
    const p = this.progress().find(x => x.fieldId === fieldId);
    const errors = this.store.all<{ row_id: number; error: string }>("SELECT row_id, error FROM _ai_cells WHERE table_id = ? AND field_id = ? AND state = 'error' ORDER BY row_id LIMIT 100", tableId, fieldId).map(r => ({ rowId: r.row_id, error: r.error }));
    const t = this.store.table(tableId);
    const missing = this.store.one<{ n: number }>(`SELECT count(*) n FROM ${t.phys} WHERE json_extract(data, '$.${fieldId}') IS NULL AND id NOT IN (SELECT row_id FROM _ai_cells WHERE table_id = ? AND field_id = ?)`, tableId, fieldId)!.n;
    return { queued: p?.queued ?? 0, done: p?.done ?? 0, total: p?.total ?? 0, errors, missing };
  }

  private forgetRows(tableId: string, ids: number[]) {
    for (let i = 0; i < ids.length; i += 100) {
      const chunk = ids.slice(i, i + 100);
      const q = chunk.map(() => "?").join(",");
      this.store.sql.exec(`DELETE FROM _ai_queue WHERE table_id = ? AND row_id IN (${q})`, tableId, ...chunk);
      this.store.sql.exec(`DELETE FROM _ai_cells WHERE table_id = ? AND row_id IN (${q})`, tableId, ...chunk);
    }
  }

  /** Drops state of fields that are gone or no longer AI fields (after schema changes). */
  prune() {
    const live = new Set(this.store.schema().fields.filter(f => f.options.ai).map(f => f.id));
    for (const { field_id } of this.store.all<{ field_id: string }>("SELECT DISTINCT field_id FROM _ai_cells UNION SELECT DISTINCT field_id FROM _ai_queue")) {
      if (live.has(field_id)) continue;
      this.store.sql.exec("DELETE FROM _ai_queue WHERE field_id = ?", field_id);
      this.store.sql.exec("DELETE FROM _ai_cells WHERE field_id = ?", field_id);
      this.store.sql.exec("DELETE FROM _ai_batches WHERE field_id = ?", field_id);
    }
  }
}
```

```ts
// Works through the AI queue from the base's alarm: at most 6 calls at once, about 25 seconds per alarm.
// An answer is written only if its queue entry was not replaced meanwhile, so edits made during a call win.
import type { BaseStore, MutationResult } from "../base/store";
import type { Attachment, Field, Row } from "../../shared/types";
import { AI_ACTOR, AI_LIMITS, aiDeps, expandPrompt, inputHash, parseAnswer, promptRefIds, systemInstruction } from "../../shared/ai";
import type { AiQueue, QueueEntry } from "./queue";
import { AiError, type ModelImage, type ModelRequest, type ModelService } from "./providers";

const IMAGE_TYPES = new Set(["image/png", "image/jpeg", "image/webp", "image/gif"]);

export interface AiHost {
  store: BaseStore;
  queue: AiQueue;
  service(id: string): Promise<(ModelService & { keyRejected: boolean }) | null>;
  call(s: ModelService, r: ModelRequest): Promise<string>;
  images(files: { key: string; type: string }[]): Promise<ModelImage[]>;
  canRun(): Promise<boolean>;
  workersLeft(): Promise<number>;
  /** Counts one call; the DO writes the counts to D1 after the batch. */
  usage(serviceId: string): void;
  rejected(serviceId: string): Promise<void>;
  publish(results: MutationResult[]): void;
  /** Rows whose AI state changed (queue.touched) and the progress per field. */
  publishStates(): void;
}

export class AiEngine {
  private recovered = false;
  constructor(private h: AiHost) {}

  nextWake(): number | null {
    return this.h.queue.nextDue();
  }

  /** The request for one cell: system instruction, expanded prompt and images. */
  async request(f: Field, row: Row): Promise<{ req: ModelRequest; cut: boolean; hash: string }> {
    const ai = f.options.ai!;
    const { store } = this.h;
    const { text, cut } = expandPrompt(ai.prompt, id => (store.maybeField(id) ? store.displayText(f.tableId, row, id) : null));
    const files: { key: string; type: string }[] = [];
    for (const id of ai.imageFieldIds ?? []) for (const a of (row.cells[id] as Attachment[] | undefined) ?? []) if (IMAGE_TYPES.has(a.type) && a.size <= AI_LIMITS.imageBytes && files.length < AI_LIMITS.images) files.push({ key: a.key, type: a.type });
    const req: ModelRequest = { system: systemInstruction(f), prompt: text, images: [], model: ai.model };
    const hash = await inputHash({ system: req.system, prompt: text, model: ai.model ?? "", service: ai.serviceId, images: files.map(x => x.key) });
    req.images = files.length ? await this.h.images(files) : [];
    return { req, cut, hash };
  }

  async drain(now: () => number = Date.now) {
    const { queue, store } = this.h;
    const start = now();
    if (!this.recovered) {
      // Calls cut off by an eviction count as a try.
      this.recovered = true;
      for (const r of store.all<{ table_id: string; field_id: string; row_id: number }>("SELECT table_id, field_id, row_id FROM _ai_cells WHERE state = 'running'")) {
        const e = queue.get(r.table_id, r.field_id, r.row_id);
        if (e) queue.postpone([e], start, x => x.tries + 1);
        queue.setState(r.table_id, r.field_id, r.row_id, e ? "queued" : "done");
      }
    }
    if (queue.nextDue() === null) return;
    if (!(await this.h.canRun())) {
      queue.postpone(queue.due(start, 100_000), start + AI_LIMITS.pause);
      return this.h.publishStates();
    }
    const busy = new Set<string>();
    const results: MutationResult[] = [];
    const running: Promise<void>[] = [];
    const key = (e: QueueEntry) => `${e.tableId}:${e.fieldId}:${e.rowId}`;
    while (now() - start < AI_LIMITS.alarmBudget) {
      const free = AI_LIMITS.concurrency - running.length;
      const next = free > 0 ? queue.due(now(), free + busy.size).filter(e => !busy.has(key(e))).slice(0, free) : [];
      if (!next.length && !running.length) break;
      for (const e of next) {
        busy.add(key(e));
        const p: Promise<void> = this.one(e, now, results).finally(() => {
          busy.delete(key(e));
          running.splice(running.indexOf(p), 1);
        });
        running.push(p);
      }
      if (running.length) await Promise.race(running);
      if (results.length) this.h.publish(results.splice(0));
      this.h.publishStates();
    }
    await Promise.all(running);
    if (results.length) this.h.publish(results);
    this.h.publishStates();
  }

  private async one(e: QueueEntry, now: () => number, results: MutationResult[]) {
    const { queue, store } = this.h;
    const f = store.maybeField(e.fieldId);
    if (!f?.options.ai || f.tableId !== e.tableId) return void queue.drop(e);
    if (store.aiBroken(f)) return queue.postpone([e], now() + AI_LIMITS.pause);
    const row = store.maybeTable(e.tableId) ? store.getRows(e.tableId, [e.rowId])[0] : undefined;
    if (!row) return void queue.drop(e);
    // Wait for AI cells this prompt reads.
    const waits = promptRefIds(f.options.ai.prompt).some(id => store.maybeField(id)?.options.ai && ["queued", "running"].includes(queue.state(e.tableId, id, e.rowId)?.state ?? ""));
    if (waits) return queue.postpone([e], now() + AI_LIMITS.debounce);
    const svc = await this.h.service(f.options.ai.serviceId);
    if (!svc || svc.keyRejected) return queue.postpone([e], now() + AI_LIMITS.pause);
    let built: { req: ModelRequest; cut: boolean; hash: string };
    try {
      built = await this.request(f, row);
    } catch (err) {
      queue.setState(e.tableId, e.fieldId, e.rowId, "error", `Could not read the images: ${err instanceof Error ? err.message : String(err)}`);
      return void queue.drop(e);
    }
    const prev = queue.state(e.tableId, e.fieldId, e.rowId);
    if (!e.manual && prev?.hash === built.hash && row.cells[f.id] !== undefined) {
      queue.setState(e.tableId, e.fieldId, e.rowId, "done");
      return void queue.drop(e);
    }
    if (svc.kind === "workers" && (await this.h.workersLeft()) <= 0) {
      queue.setState(e.tableId, e.fieldId, e.rowId, "error", "This month's Workers AI quota is used up");
      return void queue.drop(e);
    }
    queue.setState(e.tableId, e.fieldId, e.rowId, "running");
    this.h.publishStates();
    let answer: string;
    try {
      this.h.usage(svc.id);
      answer = await this.h.call(svc, built.req);
    } catch (err) {
      const ae = err instanceof AiError ? err : new AiError(err instanceof Error ? err.message : String(err), "retry");
      if (!queue.get(e.tableId, e.fieldId, e.rowId) || queue.get(e.tableId, e.fieldId, e.rowId)!.seq !== e.seq) return;
      if (ae.kind === "auth") {
        await this.h.rejected(svc.id);
        queue.setState(e.tableId, e.fieldId, e.rowId, "error", ae.message);
        queue.drop(e);
        const sameService = store.allFields().filter(x => x.options.ai?.serviceId === svc.id).map(x => x.id);
        queue.postpone(queue.due(Number.MAX_SAFE_INTEGER, 100_000).filter(x => sameService.includes(x.fieldId)), now() + AI_LIMITS.pause);
        return;
      }
      if (ae.kind === "retry" && e.tries < AI_LIMITS.retryDelays.length) {
        queue.setState(e.tableId, e.fieldId, e.rowId, "queued");
        return queue.postpone([e], now() + Math.max(AI_LIMITS.retryDelays[e.tries], ae.retryAfter ?? 0), x => x.tries + 1);
      }
      queue.setState(e.tableId, e.fieldId, e.rowId, "error", ae.message);
      return void queue.drop(e);
    }
    // The cell may have been edited, re-queued, stopped or deleted while the model was thinking.
    const current = queue.get(e.tableId, e.fieldId, e.rowId);
    if (!current || current.seq !== e.seq || !store.maybeField(f.id)) return;
    const parsed = parseAnswer(f, answer);
    if (!parsed.ok) {
      queue.setState(e.tableId, e.fieldId, e.rowId, "error", parsed.error);
      return void queue.drop(e);
    }
    queue.drop(e);
    results.push(store.updateRows(AI_ACTOR, e.tableId, [{ id: e.rowId, cells: { [f.id]: parsed.value } }]));
    // A cut prompt still counts as done; the preview reports the cut.
    queue.setState(e.tableId, e.fieldId, e.rowId, "done", null, built.hash);
  }
}
```

```ts
import { GridCellKind, type CustomCell, type CustomRenderer, type GridCell } from "@glideapps/glide-data-grid";
import type { AiCellState } from "../../shared/ai";

export interface AiData {
  kind: "rf-ai";
  state: AiCellState["s"];
  text: string;
  error?: string;
}
export type AiCell = CustomCell<AiData>;

export function aiCell(base: GridCell, state: AiCellState): GridCell {
  const text = "displayData" in base && typeof base.displayData === "string" ? base.displayData : "copyData" in base && typeof base.copyData === "string" ? base.copyData : "";
  if (state.s === "edited") return { ...base, themeOverride: { bgCell: "#fff8e6" } } as GridCell;
  return { kind: GridCellKind.Custom, data: { kind: "rf-ai", state: state.s, text, error: state.e }, copyData: text, allowOverlay: false, readonly: true } as AiCell;
}

export const aiRenderer: CustomRenderer<AiCell> = {
  kind: GridCellKind.Custom,
  isMatch: (c): c is AiCell => (c.data as AiData | undefined)?.kind === "rf-ai",
  draw: (args, cell) => {
    const { ctx, rect, theme } = args;
    const pad = theme.cellHorizontalPadding;
    const cy = rect.y + rect.height / 2;
    ctx.save();
    ctx.beginPath();
    ctx.rect(rect.x, rect.y, rect.width, rect.height);
    ctx.clip();
    ctx.textBaseline = "middle";
    ctx.font = `12.5px ${theme.fontFamily}`;
    const failed = cell.data.state === "error";
    const label = failed ? `! ${cell.data.error ?? "Failed"}` : cell.data.state === "running" ? "Generating..." : "Waiting...";
    ctx.fillStyle = failed ? "#b42318" : theme.textLight;
    ctx.fillText(label, rect.x + pad, cell.data.text ? cy - 7 : cy, rect.width - 2 * pad);
    if (cell.data.text) {
      ctx.fillStyle = theme.textMedium;
      ctx.fillText(cell.data.text.replace(/\s+/g, " "), rect.x + pad, cy + 8, rect.width - 2 * pad);
    }
    ctx.restore();
    return true;
  },
};
```
